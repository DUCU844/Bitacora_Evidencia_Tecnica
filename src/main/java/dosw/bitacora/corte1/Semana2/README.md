# Semana 2 - Bitácora Tecnica

> **Objetivo:** SOLID y Patrones de Software
## Autoevaluación
**¿Qué entendía mal antes?**
- 
- Antes tenía una idea muy superficial de las interfaces. Pensaba que eran solo una ayuda para que los métodos 
funcionaran entre clases, pero no entendía realmente su propósito dentro del diseño del sistema. 
- También escribía código más improvisado, enfocándome en que funcionara, pero sin pensar mucho en organización, 
responsabilidades o diseño limpio.
- No tenía claro qué era el desacoplamiento ni por qué era importante.

**¿Qué entiendo ahora?**
- 
- Ahora entiendo que una interfaz define un contrato que las clases deben cumplir y que ayuda a organizar mejor el 
código. 
- Comprendí mejor el principio de Responsabilidad Única (SRP), entendiendo que cada clase o método debe encargarse de 
una sola función específica para evitar sobrecarga y desorden.
- Entiendo que ejecutar mvn exec:java básicamente corre el proyecto desde el main usando Maven. 
- También soy más consciente de que el diseño previo (diagrama de clases) es importante antes de comenzar a implementar.

**¿Qué me falta reforzar?**
- 
- Comprender completamente qué es el desacoplamiento y cómo las interfaces ayudan a lograrlo.
- Sentirme más seguro implementando múltiples clases que usen la misma interfaz.
- Mejorar la claridad mental al relacionar clases entre sí.
- Practicar más para no perder ritmo cuando paso varios días sin programar.
- Reducir la dependencia de la IA y forzarme más a resolver problemas por mi cuenta.
